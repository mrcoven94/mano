# Security

Mano handles sensitive paperwork for people who can least afford a mistake. If you find a security problem, please report it privately through GitHub's "Report a vulnerability" button on this repository, not in a public issue. We will reply within three business days.

The code is public on purpose. Nothing in this repository depends on being secret: keys live outside the repo, every outside action passes the action gateway, and each person's data sits in their own agent's database.

Never put real personal information in an issue, a pull request, a test or a log. Use synthetic people.
